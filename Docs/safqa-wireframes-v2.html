Spec notes ·

    Open questions for the ERD (apply to every screen)
    1. Missing entities: Watch (watchlist), Notification (bell icon) and Message (buyer and seller chat).
    2. Report needs a reason. Fix the Report.status enum typo "dismessed" to "dismissed" (this file uses "dismissed").
    3. Bid stores a single amount. Decide whether max bid or proxy bidding is needed, and where the BD 5.000 step is stored.
    4. Listing has both currentBidder and winner. Confirm winner is set only when the auction closes.
    5. Order has no payment, delivery, address or tracking fields. Decide what sets paid: a payment webhook or a manual step.
    6. Listing has no draft status, so there is no "save draft" in the create flow.
    7. User.password is a plain String in the ERD. Store a salted hash and never return it in responses.
    8. Arabic and RTL: the market is bilingual. These screens are LTR English only; the next pass needs mirrored layouts and translations.
    9. Money: BHD uses three decimals (1 BD = 1000 fils). Every price here shows BD 0.000; confirm the stored type for Number keeps that precision.
    10. Not drawn yet: buyer-to-seller cancellations, refunds, admin-only route guard, and ended-auction notifications.
